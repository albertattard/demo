# Retrieval-Augmented Generation (RAG) - Spring AI and Ollama API

**Retrieval-Augmented Generation (RAG)** is an approach where a language model
retrieves relevant information from an external knowledge source (such as a
vector database) before generating a response. This allows the model to provide
more accurate, up-to-date, and factually grounded answers by combining its
generative abilities with retrieved context, thereby reducing reliance on its
internal (and often outdated) training data.

## Prerequisites

- [Oracle Java 25](https://www.oracle.com/java/technologies/downloads/#java25)
- [Ollama](https://ollama.com/download)

## Run the example

1. Download and setup Ollama

   If you haven’t already, please download and install Ollama from the
   [official download page](https://ollama.com/download), following the
   instructions provided. Ollama includes a command-line tool for managing and
   interacting with it.

   Models must be downloaded from a repository, such as the
   [Ollama Library](https://ollama.com/library) or
   [Hugging Face](https://huggingface.co/models). Ensure the model is saved in
   a supported format, such as
   [GPT-Generated Unified Format (GGUF)](https://huggingface.co/docs/hub/en/gguf).

   To list models installed locally, run:

   ```shell
   ollama list
   ```

   After a fresh installation, no models will be listed.

   ```

   ```

   To get started, download [LLaMA 3.1](https://ollama.com/library/llama3.1) with:

   ```shell
   ollama pull llama3.1
   ```

   internet connection.

2. Build the application

   This step assumes that Ollama is accessible on port `11434` and that the
   `llama3.1` and `nomic-embed-text` models are available. For further details,

   ```shell
   ./mvnw clean verify
   ```

   (_Optional_) Verify that the application was created.

   ```shell
   tree --prune --sort=name -L 1 './target'
   ```
