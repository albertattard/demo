# Prompt - OCI Generic API

This example shows how to prompt a generic large language model (LLM) hosted on
Oracle Cloud Infrastructure (OCI). Using OCI enables access to larger model
variants, with the assurance that your prompts are not used to train Oracle’s
foundation models.

The example calls OCI’s native API directly. While this offers full platform
capabilities, it can introduce tight coupling unless you add an abstraction layer
(a thin software layer that decouples your code from a specific provider). For
greater flexibility, consider model-agnostic libraries such as
[langchain4j](https://github.com/langchain4j/langchain4j) or
[Spring AI](https://spring.io/projects/spring-ai).

To run this example, you need an OCI API key configured on the machine or
environment executing the code. The API key (used to authenticate and
cryptographically sign requests) must be created and set up beforehand.

## Prerequisites

- [Oracle Java 25](https://www.oracle.com/java/technologies/downloads/#java25)
- [OCI Account](https://cloud.oracle.com/) and an
  [API Key](https://cloud.oracle.com/identity/domains/my-profile/auth-tokens)

## Run the example

1. Create and set up and API Key

   If you haven’t already, please create and set up the API key from the
   [Tokens and keys tab](https://cloud.oracle.com/identity/domains/my-profile/auth-tokens),
   under your profile and following the instructions provided.

   Create the `.oci/application.properties` file within the user’s home
   directory and provide the model OCID that matches the region from where the
   model will run, as shown below.

   ```properties
   model.gateway.region=eu-frankfurt-1
   model.gateway.compartmentOcid=ocid1.compartment.oc1..xxxxxxxxxxxxxxxxxxxxxxxxxxxxxxxxxxxxxxxxxxxxxxxxxxxxxxxxxxxx
   model.gateway.modelOcid=ocid1.generativeaimodel.oc1.eu-frankfurt-1.xxxxxxxxxxxxxxxxxxxxxxxxxxxxxxxxxxxxxxxxxxxxxxxxxxxxxxxxxxxx
   model.gateway.oci.configuration.type=FILE
   model.gateway.oci.configuration.file=~/.oci/config
   model.gateway.oci.configuration.profile=FRANKFURT
   ```

   Please note that some models require you to accept their terms and conditions
   before use. The model OCID (Oracle Cloud Identifier) can be found in the
   [chat playground](https://cloud.oracle.com/ai-service/generative-ai/playground/chat).

3. Run the program

   This step assumes that OCI API key and `application.properties` are both set
   up. For further details, please refer to Step 1.

   Run the example with the default prompt.

   ```shell
   java \
     --class-path './target/libs/*' \
     demo.Main
   ```

   Although the prompt remains the same, the output may vary with each run.

   ```
   prompt> When did humans first land on the Moon?
   assistant> Humans first landed on the Moon on July 20, 1969, as part of the United States' Apollo 11 mission. NASA astronauts Neil Armstrong and Edwin "Buzz" Aldrin became the first humans to set foot on the lunar surface, while Michael Collins remained in orbit around the Moon in the command module. Armstrong's famous words, "That's one small step for man, one giant leap for mankind," marked the historic moment when he stepped out of the lunar module Eagle and onto the Moon's surface.
   ```

   Run the example again with specific prompt.

   ```shell
   java \
     --class-path './target/libs/*' \
     demo.Main 'Who was the first person to walk on the Moon?'
   ```

   The model should respond with 'Neil Armstrong', as he was the first person to
   walk on the Moon.

   ```
   prompt> Who was the first person to walk on the Moon?
   assistant> The first person to walk on the Moon was Neil Armstrong. He stepped out of the lunar module Eagle and onto the Moon's surface on July 20, 1969, during the Apollo 11 mission. Armstrong's famous words as he took his first steps on the Moon were: "That's one small step for man, one giant leap for mankind."
   ```
