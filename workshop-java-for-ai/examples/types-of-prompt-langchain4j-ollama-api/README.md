# Types of Prompt - LangChain4J - Ollama API

This example demonstrates various prompt strategies for guiding the model to
produce responses in a specified format:

- **Zero-shot**: Instructs the model to perform a task without any examples.
- **One-shot**: Provides a single example before requesting a similar task.
- **Few-shot**: Offers several examples to influence the model’s behaviour.
- **Chain-of-thought (CoT)**: Encourages step-by-step reasoning by including
  intermediate steps in the prompt.
- **Constraints**: Limits the model’s output to specific values, languages, or
  tones.

The example uses [Ollama](https://ollama.com/), an open-source platform and
command-line tool that enables developers to download, manage, and run large
language models entirely on local machines—eliminating the need for cloud APIs,
access keys, or privacy-related concerns. It supports multimodal inputs, tool
calling, and integrations with REST and
[Java](https://github.com/langchain4j/langchain4j/tree/main/langchain4j-ollama),
making it well-suited for prototyping, debugging, and deploying LLM-powered
applications in a fully offline, customisable environment.

It also utilises [LangChain4J](https://github.com/langchain4j/langchain4j), a
Java-based framework for developing LLM-enabled applications, similar to
[LangChain for Python](https://www.langchain.com/). The framework includes
features for prompt management, chaining LLM calls, memory handling,
retrieval-augmented generation (RAG), and integration with external data
sources—all within the Java ecosystem.

An alternative option is [Spring AI](https://spring.io/projects/spring-ai),
which offers an abstraction layer between LLMs and applications.

Unlike other examples—such as 
[prompt-command-a-api](../prompt-command-a-api/README.md) and 
[prompt-gemini-api](../prompt-gemini-api/README.md)—this setup does not require
API keys.

## Run the example

1. Download and setup Ollama

   If you haven’t already, please download and install Ollama from the
   [official download page](https://ollama.com/download), following the
   instructions provided. Ollama includes a command-line tool for managing and
   interacting with it.

   Models must be downloaded from a repository, such as the
   [Ollama Library](https://ollama.com/library) or
   [Hugging Face](https://huggingface.co/models). Ensure the model is saved in
   a supported format, such as
   [GPT-Generated Unified Format (GGUF)](https://huggingface.co/docs/hub/en/gguf).

   To list models installed locally, run:

   ```shell
   ollama list
   ```

   After a fresh installation, no models will be listed.

   ```
   NAME                  ID              SIZE      MODIFIED
   ```

   To get started, download [LLaMA 2](https://ollama.com/library/llama2) with:

   ```shell
   ollama pull llama2
   ```

   This process may take a few seconds to several minutes, depending on your
   internet connection.


   This opens a prompt where you can engage with the model. If the model has not

3. Run the program

   This step assumes that Ollama is accessible on port `11434` and that the
   `llama2` model is available. For further details, please refer to Step 1.

   Run the example with the default prompt.

   ```shell
   java \
     --class-path './target/libs/*' \
     demo.Main
   ```

   The output should remain consistent, as the few-shot prompt guides the model
   to respond in a specific manner.

   ```
   prompt> Q: When did Albert Einstein submit his paper on special relativity to the University of Zurich?
   A: July 30, 1905

   Q: When was the first Sputnik launched?
   A: October 4, 1957

   Q: When was the first version of Java released?
   A: May 23, 1995

   Q: When did humans first land on the Moon?
   assistant> 
   A: July 20, 1969
   ```

   Run the example again with **Zero-shot prompt**.

   ```shell
   java \
     --class-path './target/libs/*' \
     demo.Main 'Who was the first person to walk on the Moon?'
   ```

   The model should respond with 'Neil Armstrong', as he was the first person to
   walk on the Moon.

   ```
   prompt> Who was the first person to walk on the Moon?
   assistant> 
   The first person to walk on the Moon was Neil Armstrong, an American astronaut who was part of the Apollo 11 mission in 1969. On July 20, 1969, Armstrong stepped out of the lunar module Eagle and onto the Moon's surface, famously declaring "That's one small step for man, one giant leap for mankind" as he took his first steps. He was followed by fellow astronaut Edwin "Buzz" Aldrin, who also walked on the Moon during the mission.
   ```

   Run the example again with **One-shot prompt**. Here the same question is
   being asked using a one-shot prompt.

   ```shell
   java \
     --class-path './target/libs/*' \
     demo.Main 'Q: Who painted the Mona Lisa?
   A: Leonardo da Vinci

   Q: Who was the first person to walk on the Moon?'
   ```

   The model responds with 'A: Neil Armstrong', following the one-shot prompt.

   ```
   prompt> Q: Who painted the Mona Lisa?
   A: Leonardo da Vinci

   Q: Who was the first person to walk on the Moon?
   assistant> A: Neil Armstrong
   ```

   Run the example using **Chain of Thought (CoT).

   ```shell
   java \
     --class-path './target/libs/*' \
     demo.Main 'When did humans first land on the Moon? Let''s think about this step by step.'
   ```

   The model responds with a detailed description about the lunar landing.

   ```
   prompt> When did humans first land on the Moon? Lets think about this step by step.

   Armstrong famously declared, "That's one small step for man, one giant leap for mankind," as he stepped out of the lunar module Eagle and onto the Moon's surface. Aldrin joined him shortly after. The two astronauts spent about two-and-a-half hours on the Moon's surface, collecting samples and conducting experiments before returning to the lunar module and lifting off for their journey back to Earth.

   Step 2 (September 14, 1970): NASA's Apollo 12 mission lands astronauts Pete Conrad and Alan Bean on the Moon's surface. This mission was significant because it marked the first time a lunar module had landed safely on the Moon after a near-miss landing during the Apollo 11 mission.

   Step 3 (January 29, 1971): NASA's Apollo 14 mission lands astronauts Alan Shepard and Edgar Mitchell on the Moon's surface. This mission was notable for being the first time a moonwalk occurred during a lunar mission.

   Step 4 (December 11, 1972): NASA's Apollo 17 mission lands astronauts Eugene Cernan and Harrison Schmitt on the Moon's surface. This mission was the last time humans visited the Moon, as the Apollo program was cancelled in 1972 due to a lack of funding.

   So, to summarize: humans first landed on the Moon in July 1969 with the Apollo 11 mission. The following missions, Apollo 12, Apollo 14, and Apollo 17, also successfully landed astronauts on the Moon's surface.
   ```
