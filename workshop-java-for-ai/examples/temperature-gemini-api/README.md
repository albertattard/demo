# Temperature - Gemini using API

This simple example demonstrates how temperature affects the model’s responses.
At lower temperatures, such as 0, the output is more deterministic, while higher
temperatures produce more varied responses.

To maintain simplicity, only the required API is used. The purpose of this
example is to illustrate the effect of temperature on its output. For actual
interaction with a model, it is advisable to use an API such as
[langchain4j](https://github.com/langchain4j/langchain4j) or
[Spring AI](https://spring.io/projects/spring-ai).

This example interacts with Google’s Gemini AI, hosted on Google Cloud. An API
key is required, available from
[Google AI Studio](https://aistudio.google.com/apikey). At the time of writing,
Google offers a generous free tier, which is more than sufficient for this
example.

## Run the example

1. Google AI Studio API Key

   If you have not already done so, please create an API key from
   [Google AI Studio](https://aistudio.google.com/apikey). This example searches
   for the key in the following order:

    1. System property: `gemini.api.key`
       (e.g. `java -Dgemini.api.key=[API-KEY] ...`)
    2. Environment variable: `GEMINI_API_KEY`
       (e.g. `GEMINI_API_KEY=[API-KEY] java ...`)
    3. File: `~/.gemini/api.key`

   For security purposes and to prevent exposing the API key in documentation,
   the following commands assume the key is saved in the `.gemini/api.key` file
   within the user’s home directory.

3. Run the program

   This step assumes that a valid Google AI Studio API key is available at
   `~/.gemini/api.key`. See Step 1 for more information about how to do this.

   Run the example with the default temperature of `0`.

   ```shell
   java \
     --class-path './target/libs/*' \
     demo.Main
   ```

   The temperature is low, which means that the output from the model will be
   consistent between runs.

   ```
   prompt> When did humans first land on the Moon?
   temperature> 0.0
   assistant> Humans first landed on the Moon on **July 20, 1969**.

   This historic event was accomplished by the United States' Apollo 11 mission, with astronauts Neil Armstrong and Buzz Aldrin being the first two people to walk on the lunar surface.
   ```

   Run the example again with the default temperature of `0`.

   ```shell
   java \
     --class-path './target/libs/*' \
     demo.Main
   ```

   As previously mentioned, a temperature of `0` does not guarantee identical
   output, even though it theoretically should. The requests may be handled by
   different hardware, potentially leading to variations in the model’s
   response.

   ```
   prompt> When did humans first land on the Moon?
   temperature> 0.0
   assistant> Humans first landed on the Moon on **July 20, 1969**, during the **Apollo 11** mission.

   The astronauts Neil Armstrong and Buzz Aldrin were the first two people to walk on the lunar surface.
   ```

   Run the example again with the higher temperature, such as `2`.

   ```shell
   java \
     --class-path './target/libs/*' \
     demo.Main 2
   ```

   The high temperature may cause the model to generate varying responses to the
   same prompt.
