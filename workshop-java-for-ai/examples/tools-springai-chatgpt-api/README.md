# Tools - Spring AI and ChatGPT API

This example demonstrates how to use tools within a prompt when working with
[ChatGPT](https://platform.openai.com/) via its client API. Given the name of a
city, the model uses a provided time tool to retrieve the current local time.
The tool requires a time zone, which the model determines automatically from the
city name. In other words, the model analyses the available tools, converts the
city name into its corresponding time zone, and then invokes the tool to obtain
the time for that location.

The example uses [Spring AI](https://spring.io/projects/spring-ai), a Java-based
framework for building applications powered by large language models (LLMs). It
provides capabilities for prompt management, LLM call chaining, memory handling,
retrieval-augmented generation (RAG), and integration with external data
sources, all within the Java ecosystem.

[LangChain4J](https://github.com/langchain4j/langchain4j) is an alternative
framework that also offers an abstraction layer between LLMs and the
application.

This example connects to OpenAI’s ChatGPT, which is hosted by OpenAI. An API
key, available from the [OpenAI](https://platform.openai.com/) platform, is
required.
