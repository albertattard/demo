# Task - Prompt - Llama2 using the Ollama API

In this task, you will develop a small Java application that accepts a prompt as
a command-line argument, sends it to the model, and prints the response. The
application will use the [Llama2](https://ollama.com/library/llama2) model
hosted locally via [Ollama](https://ollama.com/).

Through this task, you will learn how to set up and interact with a locally
hosted large language model (LLM) using Ollama. Ollama is an open-source
platform and command-line tool that allows developers to download, manage, and
run LLMs entirely on local machines—eliminating the need for cloud APIs, access
keys, or privacy concerns. It supports multimodal inputs, tool calling, and
integration with REST and [Java](https://github.com/ollama4j/ollama4j), making
it ideal for prototyping, debugging, and deploying LLM-powered applications in
an offline, customisable environment.

This example uses Ollama’s native API directly, which may result in tight
coupling with the platform unless an abstraction layer is added. For improved
flexibility, consider using an API such as
[langchain4j](https://github.com/langchain4j/langchain4j) or
[Spring AI](https://spring.io/projects/spring-ai).

This task is based on the [prompt-ollama-api](../prompt-ollama-api/README.md)
example, which you can refer to for guidance. This page also contains all the
instructions needed to get started.

1. Download and setup Ollama

   If you haven’t already, please download and install Ollama from the
   [official download page](https://ollama.com/download), following the
   instructions provided. Ollama includes a command-line tool for managing and
   interacting with it.

   Models must be downloaded from a repository, such as the
   [Ollama Library](https://ollama.com/library) or
   [Hugging Face](https://huggingface.co/models). Ensure the model is saved in
   a supported format, such as
   [GPT-Generated Unified Format (GGUF)](https://huggingface.co/docs/hub/en/gguf).

   package demo;

   import io.github.ollama4j.Ollama;
   import io.github.ollama4j.exceptions.OllamaException;
   import io.github.ollama4j.models.chat.OllamaChatMessageRole;
   import io.github.ollama4j.models.chat.OllamaChatRequest;

   import static java.util.Objects.requireNonNull;

   final class ModelGateway {

       private final Ollama ollama;

       static ModelGateway create() {
           return new ModelGateway();
       }

       String prompt(final String prompt) {
           requireNonNull(prompt);

           final OllamaChatRequest request = OllamaChatRequest.builder()
                   .withModel("llama2")
                   .withMessage(OllamaChatMessageRole.USER, prompt)
                   .build();

           try {
               return ollama.chat(request, null)
                       .getResponseModel()
                       .getMessage()
                       .getResponse();
           } catch (final OllamaException e) {
               throw new RuntimeException("Failed to make request to the model", e);
           }
       }

       private ModelGateway() {
           ollama = new Ollama();
           ollama.setRequestTimeoutSeconds(60);
       }
   }
