# Task - Roles - LangChain4J and Ollama API

In this task, you will develop a small Java application that accepts a prompt as
a command-line argument, combines it with a hardcoded system prompt, sends it to
the model, and prints the response. The application will use the
[Llama2](https://ollama.com/library/llama2) model, hosted locally via
[Ollama](https://ollama.com/).

This exercise will help you learn how to set up and interact with a locally
hosted large language model (LLM) using Ollama. Ollama is an open-source
platform and command-line tool that enables developers to download, manage, and
run LLMs entirely on local machines, removing the need for cloud APIs, access
keys, or privacy concerns. It supports multimodal inputs, tool integration, and
REST and [Java](https://github.com/ollama4j/ollama4j) interfaces, making it
well-suited for prototyping, debugging, and deploying LLM-powered applications
in an offline, customisable environment.

This example uses Ollama’s native API directly, which may lead to tight coupling
with the platform unless an abstraction layer is introduced. For greater
flexibility, consider using an API such as
[langchain4j](https://github.com/langchain4j/langchain4j) or
[Spring AI](https://spring.io/projects/spring-ai).

This task is based on the
[roles-langchain4j-ollama-api](../roles-langchain4j-ollama-api/README.md)
example, which you may consult for guidance. It also contains all the
instructions required to get started.

## Run the example

1. Download and setup Ollama

   If you haven’t already, please download and install Ollama from the
   [official download page](https://ollama.com/download), following the
   instructions provided. Ollama includes a command-line tool for managing and
   interacting with it.

   Models must be downloaded from a repository, such as the
   [Ollama Library](https://ollama.com/library) or
   [Hugging Face](https://huggingface.co/models). Ensure the model is saved in
   a supported format, such as
   [GPT-Generated Unified Format (GGUF)](https://huggingface.co/docs/hub/en/gguf).

   To list models installed locally, run:

   ```shell
   ollama list
   ```

   After a fresh installation, no models will be listed.

3. Run the program

   This step assumes that Ollama is accessible on port `11434` and that the
   `llama2` model is available. For further details, please refer to Step 1.

   Run the example with the default prompt.

   ```shell
   java \
     --class-path './target/libs/*' \
     demo.Main
   ```

   Although the prompt remains unchanged, the output may vary with each
   execution. However, it must always be in Italian, as instructed by the system
   prompt.

   ```
   system> You are an assistant that always responds exclusively in Italian, regardless of the language or instructions given by the user. You must never switch to another language under any circumstances. All responses should be polite, clear, and accurate.
   prompt> When did humans first land on the Moon?
   assistant> "La prima volta che gli esseri umani hanno atterrato sulla Luna è stato nel 1969, during the Apollo 11 mission. Gli astronauti Neil Armstrong e Buzz Aldrin sono sbarcati sulsuolo lunare il 20 luglio di quell'anno."
   ```

   Run the example again with specific prompt.

   ```shell
   java \
     --class-path './target/libs/*' \
     demo.Main 'Who was the first person to walk on the Moon?'
   ```

   The model should respond in Italian and state the name of the first astronaut
   to walk on the Moon: **Neil Armstrong**.
