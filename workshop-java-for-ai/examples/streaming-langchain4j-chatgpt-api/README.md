# Streaming - LangChain4J and ChatGPT API

This example illustrates how to stream [ChatGPT](https://platform.openai.com/)
using its client API. It performs a single prompt interaction and does not
initiate a conversational exchange with the model.

The implementation uses
[LangChain4J](https://github.com/langchain4j/langchain4j), a Java-based
framework for developing applications powered by large language models (LLMs),
similar to [LangChain for Python](https://www.langchain.com/). LangChain4J
provides tools for prompt management, LLM call chaining, memory handling,
retrieval-augmented generation (RAG), and integration with external data
sources—all within the Java ecosystem.

[Spring AI](https://spring.io/projects/spring-ai) is another framework that
offers an abstraction layer between LLMs and the application.

This example connects to OpenAI’s ChatGPT, hosted on OpenAI. An API
key—available from [OpenAI](https://platform.openai.com/)—is required.

## Prerequisites

- [Oracle Java 25](https://www.oracle.com/java/technologies/downloads/#java25)
- [OpenAI API Key](https://platform.openai.com/api-keys)

## Run the example

1. OpenAI API Key

   If you have not already done so, please create an API key from
   [OpenAI API Key](https://platform.openai.com/api-keys). This example searches
   for the key in the following order:

    1. System property: `chatgpt.api.key`
       (e.g. `java -Dchatgpt.api.key=[API-KEY] ...`)
    2. Environment variable: `CHATGPT_API_KEY`
       (e.g. `CHATGPT_API_KEY=[API-KEY] java ...`)
    3. File: `~/.chatgpt/api.key`

   For security purposes and to prevent exposing the API key in documentation,
   the following commands assume the key is saved in the `.chatgpt/api.key` file
   within the user’s home directory.

2. Build the application

   This step assumes that a valid OpenAI API Key is available at
   `~/.chatgpt/api.key`. See Step 1 for more information about how to do this.

   ```shell
   ./mvnw clean verify
   ```

   (_Optional_) Verify that the application was created and the dependencies
   copied.

   ```shell
   tree --sort=name './target/libs'
   ```

   The application JAR file and its dependencies.


3. Run the program

   This step assumes that a valid OpenAI API Key is available at
   `~/.chatgpt/api.key`. See Step 1 for more information about how to do this.

   Run the example with the default prompt.

   ```shell
   java \
     --class-path './target/libs/*' \
     demo.Main
   ```

   Although the prompt remains the same, the output may vary with each run.

   ```
   prompt> When did humans first land on the Moon?
   assistant> Humans first landed on the Moon on July 20, 1969, when Apollo 11’s lunar module Eagle touched down in Mare Tranquillitatis.

   The first humans to walk on the Moon did so the next day, July 21, 1969 (UTC). Neil Armstrong stepped onto the surface, followed soon after by Buzz Aldrin.
   ```

   Run the example again with specific prompt.

   ```shell
   java \
     --class-path './target/libs/*' \
     demo.Main 'Who was the first person to walk on the Moon?'
   ```

   The model should respond with 'Neil Armstrong', as he was the first person to
   walk on the Moon.

   ```
   prompt> Who was the first person to walk on the Moon?
   assistant> Neil Armstrong. He became the first person to walk on the Moon on July 20, 1969, during NASA’s Apollo 11 mission. He was followed by Buzz Aldrin.
   ```
